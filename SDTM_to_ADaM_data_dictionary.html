SDTM · DM

Demographics Domain

One row per subject · source for ADSL
Variable Type Role Description & expected values
STUDYID Char Key Unique study identifier. Carried forward unchanged into every ADaM dataset. e.g. "STUDY-001"
USUBJID Char Key Unique subject identifier across the study. Format: STUDYID-SITEID-SUBJID. The primary join key between DM, VS, and all ADaM datasets.
SUBJID Char SDTM Subject identifier within a site. Shorter than USUBJID; used in listings but USUBJID is preferred for all merges.
AGE Num SDTM Age in years at the time of informed consent. Integer. Used to derive AGEGR1 in ADSL.
AGEU Char SDTM Unit for AGE. Always "YEARS" in adult studies.
SEX Char SDTM Biological sex. Controlled terminology: "M" = Male, "F" = Female, "U" = Unknown. Carried into ADSL; a numeric version (SEXN) is derived.
RACE Char SDTM Subject's race per CDISC controlled terminology. e.g. "WHITE", "BLACK OR AFRICAN AMERICAN", "ASIAN". Carried into ADSL; RACEN derived.
ETHNIC Char SDTM Ethnicity. "HISPANIC OR LATINO" / "NOT HISPANIC OR LATINO". Optional in this vignette.
ARM Char SDTM Planned treatment arm description as randomized. e.g. "Drug A 10mg", "Placebo". Becomes TRT01P in ADSL.
ARMCD Char SDTM Short code for ARM. e.g. "DRUGA", "PBO". 20-character max. Becomes TRT01PN (numeric) in ADSL.
ACTARM Char SDTM Actual treatment received (may differ from ARM if subject was randomized incorrectly or switched). Becomes TRT01A in ADSL.
RFSTDTC Char SDTM Reference start date/time in ISO 8601 format (YYYY-MM-DD). Usually the date of first dose. Used to compute study day (ADY) in ADVS.
RFENDTC Char SDTM Reference end date/time. Usually the date of last dose or last observation. Used to define end of treatment period.
DMDTC Char SDTM Date of collection for the DM record (consent date). ISO 8601 format.
SDTM date convention: All dates in SDTM are stored as ISO 8601 character strings (YYYY-MM-DD or YYYY-MM-DDThh:mm:ss). ADaM converts these to numeric SAS date values (ADT) and integer study days (ADY) during transformation.
SDTM · VS

Vital Signs Domain

One row per subject per visit per test · source for ADVS
Variable Type Role Description & expected values
STUDYID Char Key Study identifier. Matches DM.STUDYID exactly.
USUBJID Char Key Subject identifier. Join key to DM and ADSL.
VSSEQ Num SDTM Sequence number. Unique within USUBJID. Ensures row uniqueness in the VS dataset.
VSTESTCD Char Key Short code for the vital sign measurement. CDISC controlled terminology. e.g. "SYSBP" (Systolic BP), "DIABP" (Diastolic BP), "WEIGHT", "HEIGHT", "PULSE", "TEMP". Becomes PARAMCD in ADVS.
VSTEST Char SDTM Long description of VSTESTCD. e.g. "Systolic Blood Pressure". Becomes PARAM in ADVS.
VSORRES Char SDTM Original result as recorded on the CRF (character). May include text or numeric values before standardization.
VSORRESU Char SDTM Original units as reported. e.g. "mmHg", "kg", "cm", "beats/min".
VSSTRESN Num SDTM Standardized numeric result. The primary source for AVAL in ADVS. All measurements converted to a single standard unit before being stored here.
VSSTRESC Char SDTM Standardized result in character format. Mirrors VSSTRESN but as text; used when result is non-numeric.
VSSTRESU Char SDTM Standardized units. Consistent across all records for a given VSTESTCD. e.g. all blood pressure values in "mmHg".
VSBLFL Char SDTM Baseline flag. "Y" if this record is designated the baseline measurement for this subject and test. Used to derive BASE in ADVS.
VISITNUM Num SDTM Numeric visit identifier. Controls chronological ordering of visits. Becomes AVISITN in ADVS.
VISIT Char SDTM Protocol visit label. e.g. "Screening", "Week 4", "Week 12", "End of Treatment". Becomes AVISIT in ADVS.
VSDTC Char SDTM Date of the vital signs assessment. ISO 8601 format. Converted to numeric ADT and integer ADY (study day) in ADVS using RFSTDTC from DM.
VSDY Num SDTM Study day of collection relative to RFSTDTC. Day 1 = first dose date. No day zero: −1 precedes day 1 directly. Cross-check for ADY derivation.
ADaM · ADSL

Subject-Level Analysis Dataset

One row per subject · derived from DM · required by all other ADaM datasets
Variable Type Role Source / Derivation
STUDYID Char From DM Copied directly from DM.STUDYID.
USUBJID Char Key Copied directly from DM.USUBJID. Primary join key for all BDS datasets.
SUBJID Char From DM Copied from DM.SUBJID.
AGE Num From DM Copied from DM.AGE.
AGEGR1 Char Derived Age group category. Derived from AGE using protocol-specified cut-points.
if AGE < 40 → "<40" | if AGE 40–64 → "40–64" | if AGE ≥ 65 → "≥65"
AGEGR1N Num Derived Numeric code for AGEGR1 to enable sorting in tables and figures.
"<40" → 1 | "40–64" → 2 | "≥65" → 3
SEX Char From DM Copied from DM.SEX. "M" / "F".
SEXN Num Derived Numeric version of SEX for sorting.
"F" → 1 | "M" → 2 | "U" → 3
RACE Char From DM Copied from DM.RACE.
RACEN Num Derived Numeric version of RACE for sorting in output tables.
TRT01P Char From DM Planned treatment for Period 1. Copied from DM.ARM.
TRT01PN Num Derived Numeric code for TRT01P. Used to sort treatment columns consistently in output.
e.g. "Drug A 10mg" → 1 | "Placebo" → 2
TRT01A Char From DM Actual treatment received in Period 1. Copied from DM.ACTARM.
TRT01AN Num Derived Numeric code for TRT01A. Same mapping as TRT01PN unless subjects received wrong treatment.
TRTSDT Num Derived Treatment start date as a numeric (SAS-style) date. Derived by converting DM.RFSTDTC from ISO 8601 character to a date value.
as.Date(RFSTDTC) in R · lubridate::ymd(RFSTDTC)
TRTEDT Num Derived Treatment end date. Derived from DM.RFENDTC in the same manner as TRTSDT.
SAFFL Char ADaM Safety population flag. "Y" if subject received at least one dose of study drug. Defines the denominator for safety analyses.
if !is.na(TRTSDT) → "Y" else "N"
ITTFL Char ADaM Intent-to-Treat population flag. "Y" if subject was randomized (ARM is not missing). Defines the primary efficacy analysis population.
if !is.na(ARM) → "Y" else "N"
PPROTFL Char ADaM Per-Protocol population flag. "Y" if subject met all protocol criteria without major deviations. In this simulated vignette, all randomized subjects are assumed PP unless otherwise specified.
ADaM convention: All flag variables (_FL suffix) take values "Y" or "" (blank, never "N") per the ADaM Implementation Guide. Numeric companion variables (_N suffix) are always included alongside character categoricals to support sorting in TLFs (Tables, Listings, Figures).
ADaM · ADVS

Vital Signs Analysis Dataset (BDS)

One row per subject per parameter per visit · Basic Data Structure · derived from ADSL + VS
Variable Type Role Source / Derivation
STUDYID Char Key From ADSL.STUDYID.
USUBJID Char Key Join key to ADSL. From VS.USUBJID.
PARAMCD Char From VS Parameter short code. Copied directly from VS.VSTESTCD.
e.g. "SYSBP" | "DIABP" | "WEIGHT" | "PULSE" | "TEMP"
PARAM Char From VS Parameter description with units appended for display. Derived from VS.VSTEST and VS.VSSTRESU.
paste0(VSTEST, " (", VSSTRESU, ")") → "Systolic Blood Pressure (mmHg)"
AVAL Num Required Analysis value. The primary numeric result for statistical analysis. Copied from VS.VSSTRESN (the standardized numeric result).
AVAL = VSSTRESN
AVALC Char ADaM Analysis value in character form. Used when AVAL is not applicable (e.g. categorical responses). Populated from VS.VSSTRESC when VSSTRESN is missing.
ABLFL Char Derived Baseline record flag. "Y" for the record designated as baseline for this subject and parameter.
if VS.VSBLFL == "Y" → "Y" else ""
BASE Num Derived Baseline analysis value. The AVAL from the record where ABLFL = "Y" for each USUBJID × PARAMCD combination, propagated to all subsequent rows.
BASE = AVAL[ABLFL == "Y"] joined back to all rows by USUBJID + PARAMCD
CHG Num Derived Change from baseline. Computed for all post-baseline records only.
CHG = AVAL − BASE (set to NA for baseline and pre-baseline rows)
PCHG Num Derived Percent change from baseline.
PCHG = (CHG / BASE) × 100 (set to NA when BASE = 0 or is missing)
DTYPE Char ADaM Derivation type. Identifies derived or imputed records. Blank for observed records. e.g. "LOCF" (Last Observation Carried Forward) for imputed records. In this vignette, all records are observed so DTYPE is left blank.
ADT Num Derived Analysis date as a numeric date value. Converted from VS.VSDTC.
ADT = as.Date(VSDTC)
ADY Num Derived Analysis study day relative to treatment start (TRTSDT from ADSL). No day zero per CDISC convention.
if ADT ≥ TRTSDT → ADY = ADT − TRTSDT + 1
if ADT < TRTSDT → ADY = ADT − TRTSDT
AVISIT Char From VS Analysis visit label. Copied from VS.VISIT. e.g. "Screening", "Week 4", "Week 12", "End of Treatment".
AVISITN Num From VS Numeric analysis visit. Copied from VS.VISITNUM. Controls chronological sort order of visits in outputs.
ANL01FL Char ADaM Analysis flag for the primary analysis (Analysis 01). "Y" for records included in the primary statistical analysis window. Excludes screening, post-treatment, and imputed records as appropriate.
if AVISITN > 0 and DTYPE == "" → "Y" else ""
TRT01P Char ADaM Planned treatment. Merged from ADSL by USUBJID. Enables treatment group comparisons within ADVS without re-merging ADSL each time.
TRT01PN Num ADaM Numeric planned treatment code. Merged from ADSL. Used for sorting treatment columns in output tables.
SAFFL Char ADaM Safety flag. Merged from ADSL. Used to subset ADVS to the safety population for analysis without re-merging ADSL.
Derivation order matters: ADSL must be finalized before ADVS is built. The correct sequence is: (1) clean and confirm DM → (2) derive ADSL including TRTSDT and all population flags → (3) merge VS with ADSL on USUBJID → (4) derive AVAL, ADT, ADY → (5) derive BASE by joining ABLFL = "Y" records back → (6) derive CHG, PCHG, ANL01FL.

SDTM → ADaM Variable Mapping Summary

Quick reference for the transformation logic in R
DM → ADSL
  • STUDYID → ADSL.STUDYID (copy)
  • USUBJID → ADSL.USUBJID (copy)
  • AGE → ADSL.AGE + derive AGEGR1, AGEGR1N
  • SEX → ADSL.SEX + derive SEXN
  • RACE → ADSL.RACE + derive RACEN
  • ARM → ADSL.TRT01P + derive TRT01PN
  • ACTARM → ADSL.TRT01A + derive TRT01AN
  • RFSTDTC → ADSL.TRTSDT (date convert)
  • RFENDTC → ADSL.TRTEDT (date convert)
  • — → ADSL.SAFFL (derive: !is.na(TRTSDT))
  • — → ADSL.ITTFL (derive: !is.na(ARM))
VS + ADSL → ADVS
  • VSTESTCD → ADVS.PARAMCD (copy)
  • VSTEST + VSSTRESU → ADVS.PARAM (concat)
  • VSSTRESN → ADVS.AVAL (copy)
  • VSBLFL → ADVS.ABLFL (copy)
  • VISIT / VISITNUM → ADVS.AVISIT / AVISITN
  • VSDTC → ADVS.ADT (date convert)
  • ADT − TRTSDT → ADVS.ADY (derive)
  • AVAL[ABLFL=="Y"] → ADVS.BASE (join back)
  • AVAL − BASE → ADVS.CHG (derive)
  • CHG / BASE × 100 → ADVS.PCHG (derive)
  • ADSL.TRT01P/PN → ADVS (merge on USUBJID)
  • ADSL.SAFFL → ADVS (merge on USUBJID)
