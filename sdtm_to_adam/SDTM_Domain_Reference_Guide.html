Identifier Variables — Present Across All Observation Domains

The following variables carry the Identifier role and appear in every observation domain (Events, Interventions, Findings, Findings About). They are not repeated on individual domain cards below to avoid redundancy. Domain-specific key variables shown on each card represent Topic, Result Qualifier, Timing, and other distinguishing variables only. Reference: SDTMIG v3.4, Section 2.2 — Variable Roles.

STUDYID Unique study identifier shared across all datasets in a submission. Required · All domains
DOMAIN Two-letter domain code matching the dataset name (e.g., AE, LB, VS). Required · All domains
USUBJID Unique subject identifier, typically STUDYID–SITEID–SUBJID concatenated. Required · All domains
--SEQ Sequence number ensuring a unique record per subject within the domain (e.g., AESEQ, LBSEQ). Required · All observation domains
--GRPID Optional grouping identifier linking related records within a domain (e.g., paired pre/post results). Optional · Permissible
--REFID Optional sponsor-defined reference ID, often used for specimen or sample tracking (e.g., lab accession number). Optional · Permissible
--SPID Optional sponsor-defined identifier mapping the record back to the original CRF or source system. Optional · Permissible
